# Security

Your text and photo are processed in your browser and never uploaded; the site loads no third-party resources. The one place where a document is uploaded is the optional paid [one-pager API](api/README.md).

If you find a vulnerability (for example markup from a text or file name being executed), please do not open a public issue. Use GitHub's private vulnerability reporting (**Security → Report a vulnerability** in this repository) or, if that is not available to you, write to **d0n@typographics-art.org**. We aim to respond within a week.
