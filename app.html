What the AI reads

This is the text inside the picture, read straight from the page. A language model, a search engine or a screen reader receives exactly this, in this order. ASCII art would give it only shading characters.

    Hide a message in this work: the work keeps only its public text, and a key records where the message's letters stand in it, at random. With the key and this work the message comes back. Keep the key like a password.

    What is Typographics Art?
    
      
    Typographics Art (TG Art) forms a picture from a given text. The text is set character for character, in its original order. Only typographic properties change from letter to letter: size, weight, colour.
    
      
    ASCII art picks a character for every cell of a grid, and the text is lost. Typographics Art turns that around: the text fixes the characters, only their typography is chosen. That makes it ASCII art for the age of AI: people see the picture, machines read the text, exactly as written.
    
    
    
    
    
      
    Three rules
    
      
      
        
    1. The text is never changed, reordered or left out. Filler text is allowed only if it is declared.
      2. 
        
    2. Text stays text: the result can be copied, searched and read by machines, and yields exactly the source text.
      3. 
        
    3. Only typography varies. No shapes, backgrounds or images besides the letters.
