What is Typographic Art?

      
Typographic Art (TG Art) forms a picture from a given text. The text is set character for character, in its original order. Only typographic properties change from letter to letter: size, weight, colour.

      
ASCII art picks a character for every cell of a grid, and the text is lost. Typographic Art turns that around: the text fixes the characters, only their typography is chosen. That makes it ASCII art for the age of AI: people see the picture, machines read the text, exactly as written.

    

    

      
Three rules

      
    
        
  1. The text is never changed, reordered or left out. Filler text is allowed only if it is declared.
    2. 
        
  2. Text stays text: the result can be copied, searched and read by machines, and yields exactly the source text.
    3. 
        
  3. Only typography varies. No shapes, backgrounds or images besides the letters.
